# Лабораторная работа №2 по ОАиП

БГУИР, группа 658304, вариант 5. Тема: «Операторы цикла» — циклические
алгоритмы, три задачи на Си.

## Задачи (вариант 5)

1. **Население города ежегодно увеличивается на 1/n наличного состава
   жителей, где n — натуральное число. Через сколько лет население города
   утроится?**
2. **Вычислить число Пи по формуле Грегори, взяв 500 членов ряда:
   П/4 = 1 − 1/3 + 1/5 − 1/7 + …**
3. **Даны целые положительные числа A и B. Найти их наибольший общий
   делитель (НОД), используя алгоритм Евклида.**

Код каждой задачи лежит в своей папке: `1/main.c`, `2/main.c`, `3/main.c`.
Пока там заглушки с условием и пометкой TODO — осталось написать циклы.

## Сборка

```bash
make            # скомпилировать задачи: 1/main .. 3/main
make report     # собрать отчёт: report/main.pdf (нужен typst)
make schemes    # перегенерить блок-схемы из main.c (нужен gostpadi)
make clean
```

Для `make schemes` нужен [gostpadi](https://pypi.org/project/gostpadi/):

```bash
pip install gostpadi
```

## Отчёт

Отчёт — `report/main.typ`, собирается на общем шаблоне `template/oaip.typ`:
титульник по образцу кафедры, типографика по СТП 01–2024 БГУИР. Листинги
в отчёт читаются напрямую из `1/main.c`…`3/main.c`, поэтому код в PDF всегда
совпадает с тем, что компилируется. Скриншоты запуска складываются в
`report/assets/`, блок-схемы gostpadi кладёт туда же (`make schemes`).
Разделы отчёта с картинками пока закомментированы — раскомментировать по
мере решения задач.

## Блок-схемы

Схемы рисует [gostpadi](https://pypi.org/project/gostpadi/) напрямую из
`main.c`: сам находит ввод-вывод, условия и циклы, сам делит схему на листы,
если она не влезает в А4.

```bash
gostpadi 1/main.c --show    # посмотреть схему прямо в терминале
gostpadi 1/main.c           # -> scheme.png рядом с кодом
make schemes                # перегенерить все три
```
