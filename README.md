# ОАиП — Лабораторная работа №2

**Операторы цикла** (БГУИР, вариант 5). Три задачи на Си: рост населения
города, ряд Грегори для числа Пи и НОД по алгоритму Евклида.

## Структура проекта

```
1/ … 3/        задачи: main.c (код)
report/        отчёт: main.typ (исходник), main.pdf (готовый), assets/ (скриншоты и схемы)
template/      общий шаблон отчёта (титульник, типографика, подписи)
Makefile       сборка программ, отчёта и схем
```

## Сборка

Все команды — из папки `home/`.

**Программы** (нужен gcc):

```bash
make            # соберёт 1/main … 3/main
./1/main        # запуск задачи 1
make clean
```

**Отчёт** (нужен [Typst](https://typst.app/open-source/)):

```bash
make report     # -> report/main.pdf
```

Исходник отчёта — `report/main.typ`, оформление подключается из
`template/arxiv.typ` (титульный лист кафедры, вёрстка тела в стиле
препринта arXiv; листинги, схемы и скриншоты вставляются сами).
Листинги программ читаются напрямую из `1/main.c … 3/main.c`.

## Блок-схемы — gostpadi

Схемы не рисуются руками: их генерирует утилита
**[gostpadi](https://github.com/sehaxe/gostpadi)** 2.0 (Rust) по
ГОСТ 19.701-90 — все линии под 90° и одной толщины, фигуры одного типа
одного размера, при нехватке места схема сама делится на листы
соединителями «А», «Б». Выход — векторный SVG, в PDF не мылится ни при
каком масштабе.

```bash
# клонировать репозиторий и поставить бинарник
git clone https://github.com/sehaxe/gostpadi && cd gostpadi
cargo install --path .

# схемы всех задач пачкой — в report/assets/
cd ../OAiP-Laba2/home && make schemes
```

Пачка одна на все задачи: gostpadi сам считает общие размеры фигур, чтобы
во всех схемах отчёта блоки одного типа получались одного размера.

## Результаты запуска

`report/make_screens.py` прогоняет каждую задачу (реальные запуски бинарников)
и складывает вывод в `report/assets/term.json`; если вывод начался не с
ожидаемого приглашения, генерация падает, чтобы рисунки не врали. Отчёт
рисует из JSON терминальные окна вектором — текст в PDF выбирается и не
мылится ни при каком зуме.
